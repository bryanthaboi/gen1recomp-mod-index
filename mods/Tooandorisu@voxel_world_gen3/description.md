# Voxel Diorama 

Voxel Diorama brings a new visual style to the Pokémon overworld, transforming traditional 2D environments into voxel-inspired scenery.

The mod aims to give the classic Pokémon games a fresh look while preserving their original charm and gameplay.

## Features 
- Voxel-inspired overworld visuals.
- A fresh perspective on classic Pokémon environments.
- Enhanced visuals without changing the core gameplay. 

## Installation
Download the latest release from GitHub and install it through the Gen1Recomp mod manager.
