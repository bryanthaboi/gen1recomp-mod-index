**Gen1BetterMenus** expands and modernizes Gen 1's menus for Gen1Recomp while preserving the original Game Boy look and feel.

## Features

- Widescreen-aware menu layouts
- Cleaner spacing and improved menu positioning
- Expanded list and options screens
- Improved PC and inventory layouts
- Better handling of dialogue and menu overlays
- UI refinements for battles, title screens, Trainer information, and other screens
- Compatibility support for multiple built-in and mod-created menu types
- Favorite/Pin Items using (START)

## Design Goal

The goal is to make Gen 1 feel **less cramped and more natural on modern displays** without turning it into a completely different UI.
