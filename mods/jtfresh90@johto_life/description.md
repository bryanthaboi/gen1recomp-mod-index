# Johto Life

Companion to **Kanto Life** for **Pokémon Gold / Silver / Crystal** on gen1recomp (**Gen 2 only**).

## Features

- **Extra NPCs** on towns and routes (0–150) with indoor counts
- **Pokémon NPCs** with **RANDOM POKE NPCS** toggle:
  - **OFF** — area-aware pools (Wilds-style town + nearby routes; water on water)
  - **ON** — full Pokédex including legendaries
- Shiny chance on Pokémon NPCs
- **Sleeping NPCs** + sleep rate % (step 5) + day sleepers
- **Common Courtesy** knocking before entering homes
- Gender-aware English names on ambient NPCs; story NPC name prefixes
- Progressive ambient dialogue (items / trades / battles after repeated talks)

## Options

**START → OPTION → JOHTO LIFE** (or Mods → Johto Life).

## Compatibility

- `games: ["gen2"]`, `gen2compat: true`
- Conflicts with `kanto_life` (use one region mod at a time)
- `github: jtfresh90/Johto-Life-Mod` enables in-app **Update** when you publish GitHub Releases
- `game_version: ">=0.0.0 <10.0.0"` covers current and near-future gen1recomp builds

## Install

Import the release zip in the mod manager, or unpack under `mods/johto_life/`.
