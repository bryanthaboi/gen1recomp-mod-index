# Kanto Dynamic Weather

Kanto Dynamic Weather transforms Dramatic Shape's voxel overworld with a dynamic 3D weather and atmospheric system for Pokémon Gen1Recomp.

Weather changes naturally between clear skies, varying cloud cover, rain, overcast conditions and thunderstorms. Clouds occupy world-space and create visible parallax while interacting with Dramatic Shape's volumetric lighting.

Features include:

- Dynamic branching weather simulation
- Clear, partly cloudy, mostly cloudy, cloudy and overcast conditions
- 3D rain and thunderstorms
- Atmospheric lightning flashes
- Rolling ground fog
- Persistent puddles that gradually evaporate after rain
- Atmospheric particles and motes
- Dynamic cloud attenuation of volumetric sunlight
- Enhanced sun and moon rendering
- Distant forests, foothills and mountain scenery beyond the loaded map
- Adjustable weather speed and atmospheric intensity
- Manual weather presets
- Dramatic Shape 1.7.2 integration

Kanto Dynamic Weather is designed as an add-on to Dramatic Shape rather than a replacement for it.

## Requirements

- Pokémon Gen1Recomp Mod API 2
- Dramatic Shape 1.7.2 or compatible 1.7.x release
- Dramatic Shape VOXEL rendering mode

Kanto Dynamic Weather does not contain or redistribute Dramatic Shape source code. Compatibility is handled through small verified runtime integration patches.
