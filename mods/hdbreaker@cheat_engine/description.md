# Cheat Engine

Cheat engine with battle, field and pokemon powers, toggled from the in-game
mod manager.

## What you get

- **Pokemon powers**: heal/XP/money, evolve, give/add pokemon, give all
  pokemon (Mew + Mewtwo to party, rest to PC), perfect DVs, shiny toggle,
  max stat exp, all badges, all TM/HM.
- **Battle powers**: always catch (incl. trainer mons), always run/crit,
  god mode, OHKO, infinite PP/items.
- **Field powers**: no encounters, spawn pokemon, bike anywhere, surf
  always, enable cut/rock, walk walls, turbo speed.

## Install

Download the zip from the [releases page](https://github.com/hdbreaker/cheat_engine/releases)
and import it with **F10** in-game, or unzip it into your `mods/` folder.

## Usage

Open the **CHEATS** row from the START menu (or the hotkey) and toggle the
powers you want. Most powers apply immediately; battle powers apply during
battles.

## Requirements

- Gen1Recomp with mod API 2 (`api: 2`)
- `engine_internals` permission (declared in the manifest)
