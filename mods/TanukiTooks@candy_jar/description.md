# Candy Jar

Adds a research quest and a custom Candy Jar item that captures excess EXP from
level-100 Pokémon and converts it into Rare Candy.

## Features

- A multi-stage research quest.
- Candy storage and retrieval.
- Conversion of banked EXP into Rare Candy.
- Support for Red, Blue, Yellow and Gold.
- Optional Quest Menu integration with ordered objectives and live progress.

## Installation

1. Download `CandyJar-1.5.0.zip` from the Releases page.
2. Import the ZIP through the Gen1Recomp launcher.
3. Enable Candy Jar.

## Compatibility

Requires Gen1Recomp 0.1.33 or newer. Quest Menu integration is optional.
