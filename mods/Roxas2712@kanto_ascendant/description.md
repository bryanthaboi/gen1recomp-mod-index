# Kanto Ascendant

Kanto Ascendant turns Pokémon Red, Blue and Yellow into a persistent training
world and adds a substantial Hall-of-Fame postgame. It builds on the original
Trainer Rematch foundation by ShaneMcGovernIE and has grown into a separate mod
with its own `kanto_ascendant` identity, progression and save migration.

## Highlights

- evolving field-trainer, Gym Leader, Master, Crown and Frontier battles
- the complete 100-species Johto Pokédex, optional early Johto migrations and
  save-local Beyond Kanto progression
- Mew and Celebi signals, legendary events, historical cups and Rocket
  Resurgence
- Route 5 breeding, Generation-II shinies, Mega Evolution and expanded
  species support
- research habitats, a spoiler-safe Atlas and persistent long-run storage
- integrated field tools, bag improvements, followers, difficulty rules and
  optional Nuzlocke/Randomizer-style runs
- English and German presentation, including compatibility with the author's
  Red, Blue and Yellow translation mods

Kanto Ascendant is actively developed. New releases preserve existing saves
where possible, but important saves should still be backed up before testing
irreversible postgame choices.

## Installation

Requires Gen1Recomp 0.1.90 or newer. Install the latest
`kanto_ascendant-<version>.zip` release through the launcher's mod manager and
resolve every reported conflict before starting the game. Older preview builds
using the former `trainer_rematch` ID must be removed from the mods directory.

The release archive contains no ROM. A separately obtained, legally owned game
is still required by Gen1Recomp.

## Compatibility

Kanto Ascendant replaces several standalone gameplay systems, including
Trainer Rematch, All Pokémon Catchable, Wilds, follower, party UI, bag,
breeding/gender and standalone Nuzlocke packages. The manifest and index entry
declare those conflicts so the launcher can stop an unsafe combination before
loading it.

One supported renderer may be used at a time. Current supported-series Voxel
Ascendant, Battle Art, Dramaless and PotatoVoxel releases are admitted by the
mod's compatibility policy; unsupported or overlapping renderer versions are
blocked.
