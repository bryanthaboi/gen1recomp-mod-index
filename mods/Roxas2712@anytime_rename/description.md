# Anytime Rename

Anytime Rename adds safe naming actions to the normal START menu. The trainer,
rival and party Pokémon can be renamed whenever the menu is available, without
visiting the Name Rater.

## Features

- rename the trainer from the START menu
- rename the rival from the START menu
- rename any owned or traded party Pokémon
- clear a nickname and restore the species name
- update the original-trainer name of the player's own party and boxed Pokémon
  after a trainer rename, while preserving traded Pokémon's original trainer
- use the correct naming screen and save fields for Gen 1 and Gen 2
- automatically switch to German labels, prompts and localized naming grids
  when a supported German translation mod is active

Names are stored in the game's normal save fields. After saving, the mod can be
disabled without reverting them.

## Installation

Install `anytime_rename-<version>.zip` through the Gen1Recomp mod manager. An
installed copy can use the launcher's **Check for updates** action for later
releases.

## Compatibility

Supports Pokémon Red, Blue, Yellow and Gold on Mod API 2. Naming actions remain
disabled during battles, link sessions and scripted scenes. The mod changes no
link-relevant gameplay data.
