# gmarcs Gen 2 Johto in First Person

First-person companion for Gen 2 (Gold/Silver/Crystal) using the active voxel renderer.

## Install

Import both `gmarcs_gen2_johto_in_first_person.zip` and `gmarcs_gen2_voxel_mod.zip`
through the engine's mod importer. Enable both in the Mods menu and restart.
Choose VOXEL → 1ST or 3RD in the game's options (or cycle with `3`).
