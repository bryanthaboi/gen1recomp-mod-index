# Quest Menu

A side-quest journal and NPC trade tracker for Pokémon Red, Blue, Yellow and
Gold.

## Features

- Populated side-quest journals for every supported game.
- Active, new-lead and completed quest sorting.
- Sequential objectives and live progress tracking.
- Immersive, Hints and Full spoiler modes.
- Staged NPC trade discovery and notifications.
- A public API that allows other mods to add quests.
- Optional Pokegear Cards integration for Gold.

## Installation

1. Download `QuestMenu-1.1.0.zip` from the Releases page.
2. Import the ZIP through the Gen1Recomp launcher.
3. Enable Quest Menu.

## Compatibility

Requires Gen1Recomp 0.1.33 or newer. Supports Red, Blue, Yellow and Gold.
Pokegear Cards is optional.
