# Soaring World

Explore Kanto from a whole new perspective!

**Soaring World** brings free flight on Dragonite to Pokémon Red, Blue and Yellow through gen1recomp.

## Features

- Explore a stylized 3D recreation of Kanto.
- Ride Dragonite with animated takeoff and landing.
- Switch between CHASE and HIGH SOAR cameras.
- Experience dynamic day/night lighting, clouds and atmospheric effects.
- Land in previously visited towns.
- Discover five repeatable Hidden Areas with unique encounters and rewards.
- Encounter rare Pokémon, version exclusives and trade evolutions.
- Uncover a mysterious secret involving Mew.
- Enjoy a new postgame event featuring Lance.

## How to Start

Become Champion and return to Pallet Town. Lance will give you the **Dragon Call**, allowing you to summon Dragonite and explore Kanto from above.

## Requirements

- Pokémon Red, Blue or Yellow
- gen1recomp `>=0.3.63 <0.4.0`
- Mod API 2

## Installation

Install through the gen1recomp mod browser, or download the runtime ZIP from GitHub Releases.

Back up your save before updating.
