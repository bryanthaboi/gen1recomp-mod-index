# Quick Select

Quick Select brings Pokémon Gold and Silver-style SELECT shortcuts to Gen 1.
Tap SELECT to use the Bicycle, or hold SELECT with a direction to use one of
four registered Bag items.

## Features

- tap SELECT for immediate Bicycle access
- register up to four Bag items on SELECT + Up, Down, Left or Right
- register, move or clear shortcuts directly from the Bag
- route every shortcut through the game's normal item-use behavior
- work with UI and graphics mods that expose alternate Bag row layouts
- integrate with Kanto Ascendant's FIELD KIT
- automatically use German labels when a supported German translation is active

## Installation

Install `jj_quick_select-v<version>.zip` through the Gen1Recomp mod manager.
An installed copy can use the launcher's **Check for updates** action for later
releases.

## Compatibility

Supports Pokémon Red, Blue and Yellow on Mod API 2. Optional integrations are
available for Kanto Ascendant and the German Red, Blue and Yellow translation
mods. The shortcuts do not alter link-relevant gameplay data.
